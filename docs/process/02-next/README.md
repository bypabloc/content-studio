## Plantilla

```markdown
---
prioridad: NN
estado: PEN
---

# <Título>

- **Objetivo**: qué cambia para el usuario.
- **Alcance**: qué entra y qué no.
- **Qué lo habilita hoy**: código, modelos o datos que ya existen.
- **Dependencias**: otras tareas o specs.
- **Preguntas abiertas**: lo que hay que decidir antes de la spec.
```
