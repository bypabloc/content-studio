# 026: cosyvoice3 de la base real tiene una instalación sin terminar

- **Qué**: en la carpeta real de motores, cosyvoice3 tiene `installing.json` (instalación interrumpida). Motores lo muestra «Con errores».
- **Por qué no se toca**: son datos del usuario. La spec no borra ni repara instalaciones que no creó.
- **Quién decide**: el usuario, con el botón «Reparar» de Motores.
- **Qué lo cierra**: cosyvoice3 en estado instalado, o un «Reparar» hecho por el usuario.
