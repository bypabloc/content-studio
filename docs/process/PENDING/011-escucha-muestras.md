# 011: escucha de la muestra lofi-chill

- **Qué**: `server/data/music/samples/lofi-chill.wav` (10 s, −16.1 LUFS, pico −1.3 dBFS, sin silencios de 0.3 s). El espectrograma muestra transitorios marcados (percusión, probablemente); el agente no los puede distinguir de un corte sin escuchar. No se detecta voz.
- **Por qué no se hizo**: si suena bien es decisión del usuario (`verify-before-claiming-done.md`).
- **Cuándo**: antes de generar las 126 muestras (ver [011-generar-muestras](011-generar-muestras.md)).
- **Quién**: usuario.
- **Qué la cierra**: que la escucha dé el visto bueno, o que pida cambiar la semilla o el estilo de la muestra.
