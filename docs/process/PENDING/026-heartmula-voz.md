# 026: heartmula: encontrar un prompt o una revisión que no cante

- **Qué**: probar HeartMuLa con otros tags o sin la sección de voz, o decidir que el motor no se usa para música instrumental. Medir con demucs (umbral -25 dB).
- **Por qué no se hizo**: decidir el prompt o quitar el motor es una decisión del usuario; el agente no tiene el criterio de gusto.
- **Cuándo**: antes de publicar, porque la regla de la música instrumental lo exige.
- **Quién**: usuario (decisión) y agente (la medición).
- **Qué la cierra**: una pista de 30 s con voz por debajo de -25 dB, o la decisión de quitar HeartMuLa de la música instrumental.
