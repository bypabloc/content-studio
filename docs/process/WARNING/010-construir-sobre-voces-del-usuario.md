# 010: el AC-7 real construiría sobre voces del usuario; se pide decisión

- **Contexto**: el paso 2.3 de `03-verificacion-final.md` pide construir una voz del catálogo que no esté construida y, si las 15 lo están, usar `Forzar` sobre una. Las 15 están construidas (`logs/studio-voices-list-010-t9.log`). Cada carpeta de voz del worktree es una unión (junction) a la carpeta real del principal, así que un build allí escribe en los datos del usuario. `build()` regenera los estilos que no aprobaron y reescribe `aprobacion.json` en cada ronda; con `Forzar`, regenera también los aprobados. Seis voces tienen estilos rechazados: cori-samuel (9 de 12), jenny (8), vctk-p329 (3), john-van-stan (2), alba-mackenna (2) y nick (2).
- **Elegida**: no correr el build real sobre las voces del principal. Eso sobrescribe voces construidas, y la spec lo marca como `blocked — user-data`. La decisión es del usuario.
- **Descartadas**: `Forzar` sobre una voz aprobada (sobrescribe datos del usuario). Un build sin forzar sobre las voces con estilos rechazados (también reescribe archivos construidos). Tomar una copia de la carpeta como prueba del paso (sirve para ver el pipeline, pero no cumple el paso tal como está escrito).
- **Cómo revertir**: no aplica. Nada se ejecutó sobre los datos reales.
- **Verificación en copia (nick)**: el build completo corrió sobre una copia (`logs/verificar-build-copia-010-t9b.log`: `RESULT nick rejected`). Tras tres rondas, `friendly` y `energetic` siguen rechazados (similitud 0,919 y 0,920; mínimo 0,93): nick queda 10 de 12. La carpeta real no cambió (25 archivos, mismo SHA-256). Consecuencia para la decisión: rehacer no garantiza aprobar. Además, `Forzar` regenera la base y todos los estilos desde cero (`build.py`: `new_base = force`), así que una voz aprobada puede quedar rechazada.
- **Cómo comprobarla**: si el usuario aprueba, `uv run studio narration voices --build <nombre>` sobre las voces que indique, y después revisar `aprobacion.json` y los `.wav` de cada estilo. Si no aprueba, AC-7 se cierra con la verificación en copia y el build real queda como PENDING.
