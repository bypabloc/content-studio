# 027: el crate de Tauri pasa a la edición de Rust 2024 (D-3)

- **Contexto**: `client/src-tauri/Cargo.toml` tenía `edition = "2021"`. La última estable de Rust (1.98.1) soporta 2024. Al cambiar la edición, cargo marcó 5 llamadas de Win32 sin `unsafe` explícito dentro de `resume_threads` (`src/server/job.rs`; el lint `unsafe_op_in_unsafe_fn`). El RED de C2 no falló por API: `getrandom` 0.4 compila sin cambios.
- **Elegida**: `edition = "2024"` y el cuerpo de `resume_threads` dentro de un bloque `unsafe`. Es lo que sugiere `cargo fix --lib`. No cambia el comportamiento.
- **Descartadas**: quedarse en 2021 (contradice «lo más actual», D-3); silenciar el lint con un `#[allow]` (oculta la necesidad de revisar el bloque).
- **Cómo revertir**: `edition = "2021"` en `client/src-tauri/Cargo.toml`. El bloque `unsafe` es válido en 2021 y puede quedarse.
- **Cómo comprobarla**: `cargo test --manifest-path client/src-tauri/Cargo.toml` sin advertencias y `python -m devtools test-runner --type=tauri-check`.
