# 026: qwen-1.7b queda en Python 3.14 (qwen-tts exige onnxruntime sin rueda cp315)

- **Contexto**: mismo caso que qwen-0.6b: `qwen-tts` 0.1.1 depende de `onnxruntime` y la versión 1.32.0 solo llega a `cp314` en Windows. Ambas recetas comparten la carpeta `.venv-qwen`.
- **Elegida**: Python 3.14 con las mismas pins que qwen-0.6b. Instalación y salida corta verificadas: 1,92 s, 24 kHz mono, -15,9 LUFS, pico -1,9 dBFS.
- **Descartadas**: 3.15 con torch 2.14.1+cu130 (sin `onnxruntime` cp315).
- **Cómo revertir**: igual que [026-qwen-0.6b-version](026-qwen-0.6b-version.md).
- **Cómo comprobarla**: `uv run studio engines install qwen-1.7b` y `narration tts --model qwen-1.7b`.
- **Pendiente**: [026-reintentar-qwen-1.7b](../PENDING/026-reintentar-qwen-1.7b.md).
