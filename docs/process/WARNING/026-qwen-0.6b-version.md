# 026: qwen-0.6b queda en Python 3.14 (qwen-tts exige onnxruntime sin rueda cp315)

- **Contexto**: `qwen-tts` 0.1.1 depende de `onnxruntime`. La versión más nueva, 1.32.0, solo tiene ruedas para Windows hasta `cp314`. Con 3.15, `uv pip compile` no encuentra solución.
- **Elegida**: Python 3.14 con torch 2.11.0+cu128, torchaudio 2.11.0+cu128, qwen-tts 0.1.1, soundfile 0.14.0 y huggingface-hub 0.36.2 (el resolutor no sube más con qwen-tts y transformers 4.57.3). Instalación y salida corta verificadas: 1,78 s, 24 kHz mono, -15,9 LUFS, pico -1,7 dBFS.
- **Descartadas**: 3.15 con torch 2.14.1+cu130 (sin `onnxruntime` cp315); huggingface-hub 2.4.0 (lo impiden qwen-tts y transformers 4.57.3).
- **Cómo revertir**: cuando `onnxruntime` tenga `cp315`, poner `"version": "3.15"` y el par torch cu130 (ver NOTES del lote) y reinstalar.
- **Cómo comprobarla**: `uv pip compile` de qwen-tts 0.1.1 con `--python-version 3.15` falla por `onnxruntime`; `uv run studio engines install qwen-0.6b` y `narration tts --model qwen-0.6b`.
