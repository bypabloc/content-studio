# 4 · Clara → `narration/voz/clara.wav`

**Intención**: preciso y sereno; articulación nítida, ritmo medio.
**Duración objetivo**: 14–16 s · **Ritmo**: medio (~140 ppm) · **Tono**: medio, estable.

## Actitud

Eres la voz de un tutorial: alguien está siguiendo tus pasos con el mouse en la mano. **Cada palabra completa**, cada consonante final presente. Calma y precisión, sin sonar robótico: es una persona amable que guía paso a paso.

## Frase por frase

| Frase | Cómo decirla |
|---|---|
| *Para comenzar, abre el panel principal.* | Instrucción 1. "**panel principal**" bien articulado, porque es lo que el usuario busca en pantalla |
| *Luego selecciona la opción Biblioteca* | Instrucción 2. "**Biblioteca**" es un nombre de botón: dilo como etiqueta, con una micro-pausa antes |
| *y presiona el botón Nuevo registro.* | "**Nuevo registro**" igual que el anterior; cierra bajando |
| *Completa los datos obligatorios y guarda los cambios.* | Dos acciones con el mismo peso y una pausa breve entre ambas |
| *El sistema confirmará la operación de inmediato.* | Cierre tranquilizador; "de inmediato" baja y termina limpio |

## Cuidado con

- **Pausas largas entre instrucciones**: son el sello de este estilo, no las acortes.
- *Para*: siempre completo, nunca "pa".
- *selecciona*: seseo ("seleksiona"), sin "θ".
- *registro*, *obligatorios*: la "g" suave, sin raspar.
- *confirmará*: con el acento en "rá", firme.
- No exageres la articulación hasta sonar a robot: es nítida pero humana.
